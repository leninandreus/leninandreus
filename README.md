## Proyecto destacado

### 🧠 Segmentación de tumores cerebrales con Deep Learning

Sistema de segmentación semántica para identificar regiones tumorales en imágenes de resonancia magnética cerebral, utilizando modelos de Deep Learning y herramientas especializadas en imágenes médicas.

**Características principales:**

- Procesamiento de imágenes médicas tridimensionales.
- Preparación y transformación del dataset Medical Segmentation Decathlon.
- Entrenamiento de modelos con PyTorch y MONAI.
- Evaluación mediante métricas especializadas de segmentación.
- Visualización de predicciones y máscaras tumorales.

**Tecnologías:** Python · PyTorch · MONAI · NumPy · Jupyter
